# Offline-Curriculum-Bot
Almost everyone studies one night before the exam and almost every time you do so, you get a new doubt
**[app.py](https://github.com/user-attachments/files/34611609/app.py)**

_This is the first version of the Curriculum Bot.
Currently, it is only able to recognize plain text and not hand written modules but I am planning to train it to be able to do that soon enough._

### **Important Instructions for use:**
1-Make sure the environment running this supports python 3.2
2-Download the version of ollama attached only to successfully run it without creating virtual environments
3-Since this works on "pyPDF" make sure to give the bot the curriculum notes in the form of a pdf only

### **How to Use?**
1-Download all the attached files and save the python source code file as "APP"
2-Bundle all these into a folder.
3-Open the folder in the terminal and pip install all the dependencies such as streamlit etc.
4-Again open the folder in terminal and type the command:
"py -m streamlit run APP.py"
5-The interface will open on your local host browser in a matter of time depending on the capability of your machine
6-Upload your curriculum file, process and index it and you are ready to go.

This is currently available for windows users only but it would soon be available to all.
